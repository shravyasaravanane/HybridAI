# Demo video script: 3:00 max, English

**Setup before recording**
- Record the **hosted app** in **Chrome desktop** with Gemini Nano already **ready** (download it in a separate session). Window 1440×900, zoom 110%, a clean profile so onboarding and the 4 demo notes appear.
- Second tab: Firebase console → **Remote Config**.
- Have a way to turn Wi-Fi off, or use the in-app offline demo (click **Online**).
- Upload to YouTube as **Public**. Add English captions (YouTube auto-captions, corrected) or burn in subtitles.

| Time | Shot | Talking points (voice-over) |
|---|---|---|
| **0:00–0:20 Problem** | Title card → a laptop on campus Wi-Fi dropping out (or a "No internet" page) → cut to the app with onboarding open | "Students take notes on flaky campus Wi-Fi, and our notes hold private stuff. Cloud AI uploads every word and dies offline. On-device AI is private, but it's not everywhere and can't read long documents. Tandem Notes uses both, through Firebase AI Logic's hybrid inference." |
| **0:20–1:10 On-device** | Onboarding: point at the three cards → **Start writing** → open *Lecture 7: CPU scheduling* → **Summarize**: bullets stream in, blue **On-device** badge, latency, "Privacy: processed on this device". Then **Action items**: a checklist appears (structured JSON). Point at the route card's *Plan: Gemini Nano → Cloud fallback (shielded)* and `InferenceMode` | "Short notes run on Gemini Nano, inside Chrome. The badge comes from the SDK's inferenceSource, so it's the truth, not a guess. This took a few hundred milliseconds and nothing was uploaded. Structured output works on-device too: same JSON schema as the cloud. The plan shows what happens if Nano fails: a cloud retry, with personal data redacted first." |
| **1:10–2:00 Airplane mode + cloud fallback** | Click **Online** to start the offline demo (or turn Wi-Fi off) → header shows **Offline** → route card switches to `ONLY_ON_DEVICE` → edit the note ("Saved offline · will sync") → **Summarize** still works. Back online → open *Client call: Priya Sharma* → routing **Cloud** → **Summarize** → orange **Cloud** badge, "Privacy Shield redacted N items" → expand **What left my device**: `[PERSON_1]`, `[EMAIL_1]`, `[PHONE_1]` → **Compare on-device vs cloud**: two cards, two latencies | "Airplane mode: everything switches to on-device. Notes keep saving and sync later. Now a note that has to go to the cloud. Before it leaves, Gemini Nano redacts names, emails and phone numbers on this device. Here's exactly what the cloud received: placeholders only. The answer is restored locally. And Compare shows the trade-off: on-device latency next to the cloud." |
| **2:00–2:30 Firebase + architecture** | Remote Config tab: set `on_device_max_chars` to 300, publish → reload the app with `?rcfresh` at the end of the URL → the lecture note now routes to **Cloud** ("Long text…"). Flip `cloud_enabled` to false → reload with `?rcfresh` → kill-switch banner. (Reset both.) Then show the README Mermaid diagram and **Insights** (on-device %, latency tiles, routing log) | "Remote Config steers the hybrid live: the routing threshold, the model, prompt templates, and a cloud kill-switch. App Check with limited-use tokens protects every Gemini call. Anonymous sign-in upgrades to Google, and Firestore syncs notes and a metadata-only routing log, offline-first. Insights shows where every request ran." |
| **2:30–3:00 Impact + close** | Insights on-device share → GitHub repo (Apache-2.0 in About) → end card: *Tandem Notes · Firebase AI Logic hybrid · Web (Chrome) · free & open source* | "Most requests never leave the device: faster, free, private, and they work offline. The cloud handles what Nano can't, and it never sees what it doesn't need to. Tandem Notes: your device thinks first." |

**Timing tip:** read the voice-over once with a stopwatch. If it runs over, cut the Compare shot first; the 1:10–2:00 segment is the one that matters most.
